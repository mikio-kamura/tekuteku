# てくてく

> **サムより:** 「ちゃんと前に進んでるか、こまめに確認しようぜ。それだけで全然違うんだよな。」

macOS のメニューバーに常駐する、定期チェックイン型の進捗管理アプリだぜ。
設定した間隔（デフォルト 20 分）ごとに「今何やってる？次は？」って聞いてくるから、ダラダラしてる暇はないよな。

---

## どんなアプリ？

- **定期チェックイン** — 一定時間おきにダイアログが出て、今のタスク・コメント・次にやること を記録させてくれるぜ
- **目標管理** — 長期・中期・短期・今週・今日 の 5 階層で目標を持てるよな
- **サムのピン** — サムが今の状況をひとこと教えてくれる小窓を画面の隅に出しておけるぜ
- **KPT 振り返り** — その日の終わりに Keep / Problem / Try を記録。過去の振り返りも見返せる
- **週次振り返り** — 週をまたぐタイミングで週次レビューも促してくれるよな
- **記録の閲覧** — 過去のチェックイン履歴をいつでも振り返れる

## セットアップ

Python 3.11 以上、macOS 専用だぜ。

```bash
git clone https://github.com/mikio-kamura/tekuteku.git
cd tekuteku
./setup.sh
```

`setup.sh` が venv を作って依存パッケージを入れてくれる。

### アプリとして使いたいなら

```bash
./make_app.sh
```

`/Volumes/ssd_pyoi/9_Application/てくてく.app` が生成されるぜ。Raycast やスポットライトから起動できるよな。

### 直接起動もできる

```bash
.venv/bin/python app.py
```

## 依存

- [rumps](https://github.com/jaredks/rumps) — macOS メニューバー用ライブラリ
- PyObjC（macOS 標準の Python に含まれてることが多いよな）

## ファイル構成

| ファイル | 説明 |
|---|---|
| `app.py` | アプリ本体。全部ここに入ってるぜ |
| `make_app.sh` | `.app` バンドルをビルドするスクリプト |
| `setup.sh` | 初回セットアップ用 |
| `autostart.sh` | ログイン時自動起動の設定スクリプト |
| `sam.png` | サムの画像 |

チェックインデータは `~/.tekuteku.json` に保存されるよな。
